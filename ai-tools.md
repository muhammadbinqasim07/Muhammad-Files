# AI Coding Tool Exploration

## 1. Which AI tool did you explore?

I explored ChatGPT.

## 2. How can it help a web developer?

ChatGPT helps developers understand programming concepts, write sample code, debug errors, explain technical topics, and generate ideas for projects. It can also help improve productivity by assisting with documentation and learning.

## 3. Can AI-generated code contain mistakes?

Yes. AI-generated code can contain bugs, security issues, or code that does not fully meet project requirements. Developers should always test and review AI-generated code.

## 4. Why should developers understand code instead of copying it directly?

Developers should understand the code so they can fix errors, improve performance, maintain applications, and write secure software. Understanding the code is essential for becoming a skilled programmer.
