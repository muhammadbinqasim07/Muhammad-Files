# MERN Overview

## MongoDB

MongoDB is a NoSQL database that stores data in flexible documents instead of tables. It is suitable for modern web applications because it can handle different types of data efficiently. MongoDB Atlas is the cloud-hosted version of MongoDB, while MongoDB Compass is a graphical application used to connect to and manage MongoDB databases.

### Answers

- What is MongoDB?
  - MongoDB is a NoSQL database used to store application data.

- Is it an SQL or NoSQL database?
  - It is a NoSQL database.

- What type of data does it store?
  - It stores data as JSON-like documents.

- What is MongoDB Atlas?
  - MongoDB Atlas is the cloud version of MongoDB.

- What is MongoDB Compass?
  - MongoDB Compass is a graphical tool for managing MongoDB databases.

## Express.js

Express.js is a backend framework for Node.js. It is used to build web servers and REST APIs. It makes routing and handling HTTP requests simple and efficient.

### Answers

- What is Express.js?
  - Express.js is a web framework for Node.js.

- Is Express.js used on the frontend or backend?
  - Backend.

- How does it help in creating APIs?
  - It provides routing and request handling.

- What is one example of an Express.js route?

```javascript
app.get("/", (req, res) => {
  res.send("Hello World");
});
```

## React

React is a JavaScript library used to build user interfaces. It is mainly used for frontend development. React uses reusable components that make applications easier to develop and maintain.

### Answers

- What is React?
  - React is a JavaScript library for building user interfaces.

- Is React used on the frontend or backend?
  - Frontend.

- What is a component?
  - A reusable piece of the user interface.

- Why are reusable components useful?
  - They save time and reduce repeated code.

---

## Node.js

Node.js is a JavaScript runtime that allows JavaScript to run outside the browser. It is mainly used for backend development. npm is the Node Package Manager used to install libraries and packages.

### Answers

- What is Node.js?
  - Node.js is a JavaScript runtime.

- Does Node.js allow JavaScript to run outside the browser?
  - Yes.

- What is npm?
  - npm is the Node Package Manager.

- How is Node.js used in a MERN application?
  - It runs the backend server and works with Express.js.
