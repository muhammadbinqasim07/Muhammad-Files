# Framework Comparison

| Technology | Programming Language | Frontend or Backend | Common Database | One Advantage |
|------------|----------------------|---------------------|-----------------|---------------|
| Node.js and Express | JavaScript | Backend | MongoDB | Fast and uses JavaScript for server-side development |
| Laravel | PHP | Backend | MySQL | Easy to build secure web applications |
| Django | Python | Backend | PostgreSQL / MySQL | Secure and includes many built-in features |

## Answers

### 1. Why is MERN called a full-stack JavaScript stack?

MERN is called a full-stack JavaScript stack because JavaScript is used for both the frontend and backend. React is used for the frontend, while Node.js and Express.js are used for the backend. MongoDB stores the application's data.

### 2. What is one major difference between Node.js, Laravel and Django?

The main difference is the programming language they use. Node.js uses JavaScript, Laravel uses PHP, and Django uses Python.

### 3. Which framework would you personally like to explore after MERN?

I would like to explore Django because it is powerful, secure, and widely used for web development.

### 4. Why will MERN be the primary stack used in this course?

MERN will be the primary stack because it is a modern full-stack technology that allows developers to build complete web applications using JavaScript.
